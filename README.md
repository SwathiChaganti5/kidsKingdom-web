# Kids Kingdom Animated React Website

React + Vite redesign using the published Kids Kingdom details and published image URLs, with a new animated preschool UI.

## Run
npm install
npm run dev

## Build
npm run build

## Included
- Home hero with floating clouds, sun, rainbow, kite and animated ball
- About, programs, Kids Play Time, activities, gallery, staff, branches and contact
- Scroll reveal animations and hover interactions
- Gallery lightbox
- Responsive mobile navigation
- Existing published school contact/branch/staff information
- Published school image URLs for logo, gallery and staff/admission visuals
